# Adarsh Jaiswal — Portfolio Website

A responsive, dark-themed personal portfolio highlighting experience in data analytics, compensation benchmarking, reporting and workflow automation.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and small interactions

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. After deployment, the site will be available at:
   `https://addu2138.github.io/adarsh.jaiswal/`

## Notes
The CV download button is not included because a CV file was not part of the uploaded website files. Add a PDF/DOCX under an `assets` folder before linking it from the page.
